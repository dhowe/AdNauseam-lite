## Description

**AdNauseam MV3** is the [MV3 API](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3)-based version of [AdNauseam](https://adnauseam.io), built on top of uBO Lite.

The source code lives in the [AdNauseam](https://github.com/mneunomne/AdNauseam) repository, under `platform/mv3`. This repository holds it as a git submodule and publishes the release packages.
